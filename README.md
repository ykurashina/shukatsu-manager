# 就活管理 (shukatsu-manager)

ブラウザで動作する、29卒向けの新卒就活管理シングルページアプリケーション（SPA）です。個人情報はすべてローカル（ご自身のパソコン内）で完結し、外部のサーバーには送信されません。

## 🚀 起動と終了
- **起動**: デスクトップの「就活管理」アイコンをダブルクリック、または `起動する.bat` を実行します。
- **終了**: アプリが開いているブラウザのタブ（またはウィンドウ）を閉じるだけです。約10秒後に裏のPythonサーバーが自動的に検知して自己終了（シャットダウン）します。

## 📁 フォルダ構成と役割

### 1. アプリの起動と土台
*   `起動する.bat`: アプリ起動用のWindowsバッチファイル。
*   `server.py`: ハートビート監視機能付きの自動停止型ローカルWebサーバー（Python）。
*   `index.html`: アプリ全体の骨組みを定義する唯一のHTMLファイル。
*   `.gitignore`: 就活データ（JSON）等の個人情報をバージョン管理から除外する設定。

### 2. デザインシステム（CSS）
*   `css/variables.css`: 色、文字サイズ、余白などの共通デザイン変数。
*   `css/base.css`: 表示リセットと基本フォント設定。
*   `css/layout.css`: サイドバーやメイン領域のレスポンシブ（画面幅追従）レイアウト。
*   `css/components.css`: ボタン、入力欄、モーダル、トーストなどの共通パーツデザイン。
*   `css/*.css` (個別画面CSS): 各画面（カレンダー、カンバン等）特有のデザイン調整。

### 3. コアシステム（JavaScript）
*   `js/app.js`: アプリ起動時の初期化、保存先セットアップ画面、全体の統括。
*   `js/store.js`: データ管理室。ファイル直接保存とブラウザ保存の切り替え、自動保存、CRUD処理。
*   `js/router.js`: 画面の切り替え（SPAルーター）の処理。
*   `js/utils/date.js`: 日付フォーマット変換、カレンダー日付生成、残り日数計算。
*   `js/utils/api.js`: RSSニュースフィード取得（rss2json.com経由）と gBizINFO API 連携ユーティリティ。

### 4. 共通UIコンポーネント（JavaScript）
*   `js/components/sidebar.js`: 画面左側のメニューバーの構築。
*   `js/components/modal.js`: 画面中央に表示される入力用ポップアップ窓。
*   `js/components/toast.js`: 画面右上にお知らせを表示するメッセージ機能。
*   `js/components/form-utils.js`: パスワード表示切替や、文字数制限カウンター付き入力欄の生成。

### 5. 各画面のプログラム（JavaScript）
*   `js/views/dashboard.js`: ダッシュボード（KPI統計、直近の予定、緊急アクション、就活ニュースフィード）。
*   `js/views/companies.js`: 企業一覧テーブル、詳細モーダル、選考ステップ登録（動的フォーム）、gBizINFO検索。
*   `js/views/kanban.js`: 進捗ステータスごとのカンバンボード。
*   `js/views/calendar.js`: 月間カレンダーと日付ごとの予定詳細サイドパネル。
*   `js/views/es-manager.js`: ES設問下書き、提出日・文字数カウント管理、自己分析ノートからの挿入機能。
*   `js/views/interviews.js`: 面接官人数、雰囲気、質問、反省点の記録。
*   `js/views/notes.js`: 自己分析や自己PRなどのネタ帳（カテゴリ別）。
*   `js/views/bookmarks.js`: 就活サイトや企業研究用サイトなどのリンク集。
*   `js/views/settings.js`: バックアップ（JSON）のエクスポート/インポート、データ削除。

## ⚙️ 技術仕様・設計ルール（AI開発用）

アジャイル開発を継続するにあたり、以下の設計思想および技術仕様を厳守してください。

1.  **データ永続化（ハイブリッド自動切替）**
    *   `File System Access API` に対応しているブラウザ（Chrome/Edge推奨）では、ローカルJSONファイルへの直接書き込みを優先。
    *   非対応ブラウザまたは拒否された場合は `LocalStorage` にフォールバックし、手動バックアップ（エクスポート/インポート）を明示的に案内する。
2.  **自動サーバー終了（ハートビート）**
    *   ブラウザ側 (`app.js`) から 3秒ごとに `/heartbeat` を fetch。
    *   サーバー側 (`server.py`) は 10秒以上ハートビートが途絶えたら自動で `shutdown()` する。
3.  **パスワードセキュリティ**
    *   マイページログイン用のパスワードは、手軽さを優先して平文（プレーンテキスト）で保管する。
    *   ただし、入力画面や詳細画面では「目のアイコン」によるマスク切り替えを表示し、下部に「他者と共有するPCでは保存を避けてください」というセキュリティ警告を必ず明記する。
4.  **画面の構築ルール**
    *   シングルページアプリケーション（SPA）構成のため、各画面は `render()` でプログラム的にDOMを構築し、`init()` でイベントリスナーの登録、`destroy()` でクリーンアップを行うライフサイクルを維持する。
5.  **gBizINFO API 連携（オプショナル）**
    *   設定画面でAPIトークンを登録すると、企業追加フォームに「gBizINFOで企業情報を検索」ボタンが表示される。
    *   検索結果（所在地・資本金・従業員数・設立日）は企業のメモ欄に自動挿入される。
    *   トークン未設定時はボタン自体が非表示となり、アプリの他の機能には一切影響しない。
6.  **RSSニュースフィード**
    *   ダッシュボードに就活ニュースパネルを表示。`rss2json.com` を経由してCORS制約を回避し、マイナビニュース等のRSSフィードをJSON形式で取得する。
    *   最新5件のヘッドラインを表示し、クリックで元記事にジャンプ。手動更新ボタン付き。
7.  **自己分析ノート → ES挿入連携**
    *   ES管理の編集モーダルに「ネタ帳から挿入」セクションを設置。自己分析ノートに登録済みのネタをドロップダウンで選択し、回答欄のカーソル位置にワンクリック挿入できる。
